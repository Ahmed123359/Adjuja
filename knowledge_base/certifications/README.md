# certifications/ — Certifications et accréditations

Ce dossier contient les certifications officielles de l'entreprise.

## Contenu typique

- Certificats ISO (qualité, sécurité, environnement)
- Qualifications professionnelles et agréments sectoriels
- Labels et accréditations

## Usage par le RAG

Le LLM s'en sert pour valoriser les certifications dans les sections
"Garanties qualité" ou "Engagements" d'une réponse AO, et pour répondre
aux critères de qualification qui l'exigent explicitement.
