# resources/ — Moyens humains et matériels de l'entreprise

Ce dossier contient les documents décrivant les capacités opérationnelles
de l'entreprise : équipes, profils d'experts, moyens matériels.

## Contenu typique

- Listes nominatives de l'équipe proposée (avec profils et rôles)
- Notes sur les moyens humains et matériels
- CVs des experts clés (anonymisés si besoin)
- Organigrammes de mission

## Usage par le RAG

Le LLM s'en sert pour enrichir les sections "Moyens humains", "Équipe projet"
et "Organisation de la mission" dans les réponses générées. Ces documents
permettent de présenter des profils réalistes et cohérents avec les exigences
de l'AO (qualifications, années d'expérience, domaines de compétence).
