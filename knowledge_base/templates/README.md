# templates/ — Offres techniques soumises (réponses AO passées)

Ce dossier contient les documents techniques rédigés par l'entreprise
dans le cadre de réponses à des appels d'offres passés.

## Contenu typique

- Notes méthodologiques (approche, démarche, plan d'intervention)
- Notes d'évaluation et diagnostics
- Plannings et chronogrammes de mission
- Notes logistiques

## Usage par le RAG

C'est le dossier le plus précieux pour la génération. Le LLM y puise :
- Le **style rédactionnel** de l'entreprise (ton, structure, niveau de détail)
- Le **contenu méthodologique** réutilisable (approches, frameworks, étapes)
- Des **exemples concrets** adaptables à un nouvel AO similaire

Privilégier les offres gagnantes. Regrouper par domaine si le volume augmente.
