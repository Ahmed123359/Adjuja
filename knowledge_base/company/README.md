# company/ — Documents institutionnels de l'entreprise

Ce dossier contient les documents légaux et institutionnels fixes de l'entreprise,
qui ne changent pas d'un AO à l'autre.

## Contenu typique

- Procès-verbal de gérance
- Statuts de la société
- Présentation générale / plaquette commerciale
- Tout document identifiant l'entreprise (RC, patente, etc.)

## Usage par le RAG

Le LLM s'en sert pour contextualiser l'entreprise : sa forme juridique,
son ancienneté, son positionnement. Ces informations enrichissent les sections
"Présentation du soumissionnaire" dans les réponses générées.
