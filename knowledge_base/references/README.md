# references/ — Références et attestations clients

Ce dossier contient les preuves d'expérience passée de l'entreprise :
missions réalisées, clients servis, attestations de bonne exécution.

## Contenu typique

- Attestations de référence signées par des clients publics ou privés
- Fiches projets (contexte, mission, résultats)
- Lettres de recommandation

## Usage par le RAG

Le LLM s'en sert pour alimenter les sections "Références" et "Expérience"
d'une réponse AO. Plus les références couvrent des domaines variés
(formation, évaluation, conseil, SI...), plus les réponses seront pertinentes
quelle que soit la nature de l'AO.
